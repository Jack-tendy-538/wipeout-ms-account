# woma(wipeout-ms-account)
一键清除Microsoft账户
当你无意间看到，你在不该登微软账户的时候登了它，然后看到这个……
<img width="1101" height="360" alt="image" src="https://github.com/user-attachments/assets/2625bf29-1f6f-44bf-a18f-ce9316f1eef8" />
这个仓库旨在一键退登windows电脑上的微软账户（~~能不能就是另一回事了~~）

## 用法
1. 下载[woma.ps1](https://github.com/Jack-tendy-538/wipeout-ms-account/raw/refs/heads/main/woma.ps1)，顺手在文件属性勾选“”解除锁定
2. 用管理员身份运行powershell
3. 先修改脚本运行策略（若有必要）
4. cd到你的`woma.ps1`所在的文件夹，然后运行`.\woma.ps1`
5. 大功告成！请打开设置，检查账户情况
