# woma(wipeout-ms-account)
> ![important] 此软件仅在Windows 10/11系统上运行，且仅支持Microsoft账户登录的系统。~~反正Linux,MacOS和安卓不支持~~

> ![important] 该软件仅在公用设备（如网吧、图书馆、学校机房等）上使用，且仅在用户登录Microsoft账户后使用；因退登导致的账户退登（？）、数据丢失或其他问题，作者不承担任何责任。

一键退登Microsoft账户，清除所有与Microsoft账户相关的本地数据。

## 食用方法
1. 在[release页面](https://github.com/Jack-tendy-538/wipeout-ms-account/releases)下载最新版本的woma.exe，双击运行。
2. 如果系统弹出UAC（用户账户控制）窗口，请点击“是”按钮。
3. 阅读并同意免责声明后，点击“确定”按钮。
4. 在选择窗口中选择你要退登的项目，在下拉框中选择使用的策略，然后点击“确定”按钮。
5. 等待程序运行完成。

> ![important] 注意，应确保在运行该软件时，系统中没有其他用户登录Microsoft账户，否则可能会导致数据丢失或其他问题；杀毒软件可能会拦截此软件对注册表的修改，建议在运行前关闭杀毒软件的相关功能。
